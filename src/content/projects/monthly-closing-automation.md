제조업의 월결산 Excel 업무를 자동화하는 데스크톱 앱 개발에 참여했다. 원천 자료를 읽어 기존 결산 양식의 파일을 생성하고, 담당자가 분류와 배부 기준을 보정한 뒤 후속 계산을 이어가는 프로그램이다. Electron, TypeScript와 ExcelJS를 사용하고 Windows 설치파일로 배포했다.

화면은 고객명과 로고를 제외하고 파일명, 업무명과 경로를 예시로 치환한 실제 앱 UI다. 등록 자료와 계산 결과 상태도 가상으로 구성했다.

## 기존 Excel 업무와 자동화 범위

결산은 여러 파일이 서로의 값을 참조하는 구조였다. 당월 원천 자료로 계산한 값을 다른 파일에 전달하고, 전월 확정본은 다음 달의 기초로 이어졌다. 담당자가 중간에 품목을 분류하거나 배부 기준과 금액을 수정하는 과정도 있었다.

기존 Excel 양식과 담당자의 수정 방식을 유지하면서 이 흐름을 앱으로 연결했다. 파일 하나를 만드는 기능에 더해, 실행 순서와 입력 대기, 수정 후 재계산, 최종 확정까지 다뤄야 했다. 담당자가 Excel에서 고친 산출물을 다시 읽어 계산에 반영하는 경로도 포함했다.

## 담당한 부분

동료와 파일별 생성 엔진 및 검증 작업을 분담했다. 나는 원재료, 외주, 유형자산과 재고 관련 생성 기능을 개발하고, 각 기능을 자료 등록부터 일괄 실행과 결과 검토까지 연결했다. 개별 파일의 생성 기능과 함께 아래 공통 부분을 맡았다.

- 통합 문서 단위의 수식 계산, 수식 저장값 기록과 외부 링크 보존
- 담당자 입력과 Excel 수정 반영, 잠정 결과와 최종 확정의 상태 관리
- 파일 사이 전달값을 비교하는 반복 계산, 종료 조건과 최종 검사
- 계산 작업의 worker 분리, 실행 기록과 진단자료 내보내기
- Windows 설치파일 빌드, 태그 기반 릴리즈와 앱 내 자동 업데이트

## 현업 피드백과 잠정 결과

초기 일괄 실행은 담당자의 판단이 필요한 단계에서 멈췄다. 중간 시연에서는 미판정 항목이 있어도 전체 파일을 먼저 확인하고 수정할 수 있게 해 달라는 요청을 받았다. 앞 단계 입력을 마칠 때까지 뒤 파일을 볼 수 없는 흐름이 실제 작업 방식과 맞지 않았다.

동료와 일정 및 기존 기능에 미칠 영향을 검토한 뒤, 확인 전인 값이 있어도 후속 파일을 잠정 생성하도록 바꿨다. 결과 화면에서는 지금 처리할 수 있는 일과 앞 단계를 기다리는 일을 나누고, 입력을 반영하면 필요한 후속 계산을 이어가게 했다.

잠정 결과는 최종 확정과 구분했다. 미판정이나 검증 오류가 남아 있으면 확정을 막고, 잠정 파일이 다음 달의 확정 입력으로 재사용되지 않도록 했다. 수정본을 반영하거나 계속 실행할 때 담당자가 고친 파일을 덮어쓰는 경우도 확인하도록 했다.

## 파일 간 참조와 전월 확정값

월별 시트를 만들거나 행이 늘어나면 그 파일을 읽는 후속 파일의 참조도 함께 맞춰야 했다. 수식 문자열을 옮기는 작업 외에, 참조 대상 파일과 시트, 계산된 저장값을 함께 다뤘다. 계산되지 않은 참조를 정상적인 0으로 읽지 않도록 빈칸, 오류와 저장값 부재도 구분했다.

당시 사용한 ExcelJS로 산출물을 저장하면서 XLSX의 외부 링크 부품이 보존되지 않는 문제도 있었다. 템플릿의 링크 목록과 관계 파일을 읽어 산출물에 복원하고, 다시 읽거나 다음 생성의 템플릿으로 사용해도 참조가 이어지는지 검사했다.

과거 월의 확정값은 당월 계산과 분리해 보존했다. 파일들이 값을 주고받는 반복 계산에서는 전달값을 비교해 종료 여부를 판단하고, 최종 검사 후 결과를 채택하도록 했다. 계산을 끝내는 조건과 결과를 확정할 수 있는 조건을 따로 다뤘다.

## 실행과 배포

일괄 계산과 Excel 생성은 Node.js worker thread로 옮겼다. 진행 상태를 main에 전달하고 실행 기록의 저장 결과를 worker에 되돌려, 기록에 실패하면 다음 단계로 넘어가지 않도록 했다. worker 종료 전에는 실행 잠금을 유지하고 결과 없이 끝난 경우도 실패로 처리했다.

담당자가 실행 이력과 실패 상황을 다시 확인할 수 있도록 기록 조회와 진단자료 내보내기를 제공했다. Windows 설치파일은 태그 기반으로 빌드하고 앱 내 자동 업데이트를 연결했다. 사용 설명서에는 실제 작업 순서와 함께 수정 반영, 확정과 백업 방법을 정리했다.

## 검증 범위

원천 자료와 기존 결산본을 대조하고, 값뿐 아니라 수식, 시트 구성과 외부 참조를 확인하는 회귀 시험을 구성했다. 기존 결산본과 차이가 있는 항목도 비교 기준을 고정해, 이미 알려진 차이 안에서 새로 값이 바뀌는 경우를 놓치지 않도록 했다. 중단 후 계속 실행, 수정본 보존과 확정 사본 복구도 시험에 포함했다.

실자료 검증은 월과 자료 버전을 정해 수행했다. 자동 시험과 앱에서 확인한 결과를 Windows Excel의 재계산 및 담당자의 최종 금액 검수와 구분해 관리했다.
